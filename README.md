# ShopSphere 360

## Enterprise Business Intelligence & Customer Analytics Platform

ShopSphere 360 is an end-to-end Business Intelligence and Data Analytics project designed for a fictional e-commerce company.

The project demonstrates the complete journey from business problem identification and requirements analysis to data engineering, SQL analytics, Python analysis, Power BI dashboards, and data-driven business recommendations.

## Project Role

**Business & Data Analyst**

## Business Domain

E-Commerce / Retail

## Objectives

- Analyze sales and profitability
- Understand customer behavior
- Identify high-value customers
- Analyze customer churn and retention
- Evaluate marketing performance
- Analyze product performance
- Investigate returns and customer support
- Build executive-level Power BI dashboards
- Provide actionable business recommendations

## Technology Stack

- Python
- Pandas
- NumPy
- SQL / MySQL
- Power BI
- DAX
- Power Query
- Git & GitHub
