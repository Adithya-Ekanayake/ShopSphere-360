# ShopSphere 360 — KPI Dictionary

## 1. Purpose

The KPI Dictionary defines the standardized business metrics used throughout ShopSphere 360.

All SQL queries, Python analyses, and Power BI dashboards should follow these definitions to ensure consistency across the project.

---

## 2. KPI Governance Principles

- Every KPI must have a documented definition.
- KPI calculations must use consistent business rules.
- KPI results must be traceable to source data.
- KPI definitions must be understandable to business stakeholders.
- Changes to KPI logic must be documented.
- The same KPI should produce consistent results across dashboards.

---

|---|---|
| KPI ID | KPI-001 |

# 12. KPI Governance

Every KPI should have:

- Unique KPI ID
- Business definition
- Formula
- Data source
- Business owner
- Analytical dimensions
- Refresh frequency
- Validation rules
- Dashboard destination

---

# 13. KPI Validation

Before publication, KPI calculations should be validated against:

1. Source transaction data
2. SQL calculations
3. Python calculations
4. Power BI calculations

Any discrepancy should be investigated before the KPI is presented to stakeholders.

---

# 14. KPI Success Criteria

The KPI framework is considered complete when:

- All critical business KPIs have documented definitions.
- Formulas are clearly defined.
- KPI ownership is assigned.
- Data sources are identified.
- KPIs are consistently implemented across analytical tools.
- KPI results can be validated.
